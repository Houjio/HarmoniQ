# HarmoniQ

## Description
Voici le projet HarmoniQ. Plus d'informations à venir.

## Installation de la version stable

Pour installer la version stable (v0.1.0) depuis GitHub, utilisez la commande suivante :

```bash
pip install git+https://github.com/Houjio/HarmoniQ.git@stable
```

Ou si vous préférez cloner le dépôt et installer depuis la branche stable :

```bash
git clone https://github.com/Houjio/HarmoniQ.git
cd HarmoniQ
git checkout stable
pip install -e harmoniQ/
```
