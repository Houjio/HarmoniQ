Résumé
------

1. Cloner le dépôt, se placer à la racine.
2. Lancer ``./exec_harmoniQ.sh`` (recommandé) ou suivre :doc:`install` puis :doc:`app`.
3. Aucun fichier ``demande.db`` n'est requis : des données synthétiques sont utilisées si la base est absente.
